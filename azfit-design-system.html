Responsive Breakpoints

Layout behavior across device sizes.

Desktop (>1024px)
Full sidebar, multi-column grids
Tablet (768-1023px)
Sidebar hidden, 2-column grids
Mobile (<768px)
Single column, hamburger menu

Dropdowns

Custom select styling demonstrated in Form Elements above. Dropdown menus animate with opacity and translateY.

Hover States

All hover states are demonstrated within their respective component sections. Cards lift, buttons darken, links change color.

Transitions

Global transition tokens: fast (150ms), base (300ms), slow (500ms). Applied to colors, transforms, shadows, and opacity.

Micro-interactions

Small delightful details: check badge pop, checkbox bounce, FAB pulse, toast slide, progress fill. See Animation Library for specs.

Grid System

Layout uses CSS Grid and Flexbox. Selection cards use auto-fill minmax(160px,1fr). Stats use similar responsive grids. All spacing follows 4px base unit.
